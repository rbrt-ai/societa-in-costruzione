# Contribuire a Società in Costruzione

Sono benvenute correzioni, domande, fonti verificabili e proposte formulate con rispetto.

## Prima di iniziare

- Leggi `docs/metodo.md` e `docs/partecipa.md`.
- Controlla che non esista già una discussione o issue simile.
- Non pubblicare dati personali, materiale riservato, credenziali o chiavi.
- Distingui fatti, interpretazioni, ipotesi causali, stime, valori e incertezze.
- Descrivi alternative, benefici, costi, rischi, gruppi coinvolti e limiti.

Issue, pull request e Discussions sono pubbliche. Non inserire nomi, email, recapiti o altre
informazioni che possano identificare te o terze persone.

## Aggiungere una proposta

1. Copia `docs/proposte/template.md` in `docs/proposte/`.
2. Usa un nome file breve, minuscolo e separato da trattini.
3. Mantieni tutte le sezioni del modello.
4. Collega fonti reali e descrivine i limiti.
5. Rappresenta argomenti favorevoli e contrari.
6. Indica condizioni di modifica o abbandono.
7. Aggiungi la pagina alla navigazione in `mkdocs.yml`.
8. Esegui `mkdocs build --strict`.

Quando mancano informazioni affidabili, dichiaralo esplicitamente. Non aggiungere percentuali,
costi, risultati, studi o citazioni senza una fonte verificata.

## Proporre una modifica

1. Crea un fork del repository.
2. Crea un ramo con un nome breve.
3. Modifica i file Markdown o la configurazione.
4. Esegui `mkdocs build --strict`.
5. Apri una pull request usando il modello incluso.

## Regole di collaborazione

- Critica argomenti e proposte, non persone.
- Evita linguaggio aggressivo, discriminatorio o propagandistico.
- Non presentare una preferenza come fatto.
- Dichiara ruoli o interessi pertinenti senza pubblicare dati superflui.
- Accetta che un contributo possa essere corretto, unito o archiviato.

La versione iniziale non dispone ancora di un comitato editoriale indipendente. I contributi sono
valutati per chiarezza, verificabilità, trasparenza e aderenza al metodo.
